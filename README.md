# eco-ai-learning

用 Python 处理城市环境空气质量监测数据的练习项目。

当前实现了两个功能：把 AQI 数值判定为空气质量级别，以及读取监测数据 CSV 批量出统计结果。

## 项目结构

```
eco-ai-learning/
├── aqi_level.py        AQI 分级模块（可单独运行自测）
├── air_report.py       日报统计工具（主入口）
├── fuzhou_air.csv      监测数据（输入）
├── report_output.csv   带级别的完整结果（输出，运行后生成）
└── README.md
```

## 分级依据

HJ 633—2026《环境空气质量指数（AQI）技术规定》，2026 年 3 月 1 日实施，替代 HJ 633—2012。

浓度限值涉及 GB 3095—2026《环境空气质量标准》（本项目暂未实现浓度→AQI 换算，见「待办」）。

## 使用方法

### 1. 批量统计（主要用法）

把监测数据放在与脚本同目录的 `fuzhou_air.csv`，然后运行：

```bash
python air_report.py
```

输入 CSV 必须包含 `date` 和 `aqi` 两列，其余列会原样保留：

| 列名 | 含义 | 是否必需 |
|---|---|---|
| date | 监测日期，YYYY-MM-DD | 是 |
| aqi | 空气质量指数 | 是 |
| city | 城市名 | 否 |
| pm25 / pm10 / so2 | 污染物日均浓度，µg/m³ | 否 |

运行后会在同目录生成 `report_output.csv`，在原表基础上追加「等级」「颜色」「健康建议」三列，采用 utf-8-sig 编码保存，Excel 双击打开不会乱码。

### 2. 单独跑分级模块自测

```bash
python aqi_level.py
```

会用一组覆盖各级别临界值的样例数据（43、52、100、101、151、150、500）验证区间判定是否正确。

## 已知限制

- **只处理 AQI，不判定首要污染物。** 现有数据缺 O₃、NO₂、CO 三项，无法按标准判定首要污染物。夏季臭氧为主控污染物的时段，仅看 AQI 会丢失关键信息。
- **不做输入校验。** AQI 传入负值会被判为「优」，超过 500 会被判为「严重污染」，脚本不会报错。真实监测数据中的异常值需在上游清洗。
- **不区分有效监测天数。** 统计以 CSV 实际行数为准，缺测日需自行剔除后再计算优良率。

# aqi_level —— AQI等级判断程序
这是一个判断aqi等级的程序
## 分级依据
HJ 633—2026《环境空气质量指数（AQI）技术规定》（2026年3月1日实施，替代 HJ 633—2012）
## 运行方法
python aqi_level.py
## 输出示例
第1天,AQI=43 优 绿色 各类人群可正常活动
第2天,AQI=52 良 黄色 极少数异常敏感人群应减少户外活动
第3天,AQI=100 良 黄色 极少数异常敏感人群应减少户外活动
第4天,AQI=101 轻度污染 橙色 敏感人群减少外出
第5天,AQI=151 中度污染 红色 一般人群适量减少户外运动，敏感人群一般不外出
第6天,AQI=150 轻度污染 橙色 敏感人群减少外出
第7天,AQI=500 严重污染 褐红色 敏感人群应当留在室内，一般人群停止户外运动
优：1天
良：2天
轻度污染：2天
中度污染：1天
严重污染：1天
